## How to test (important, learned the hard way)

- Chrome extension screenshots are cropped to 1254×604 of the 1536×740 viewport → set `document.documentElement.style.zoom='0.8'` via javascript_tool to see the whole width (do NOT zoom on Leaflet map pages — tiles mis-size). Click coordinates are in the screenshot frame. Prefer `find` + ref clicks or JS `.click()` for reliability.
- The tab reports `visibilityState=hidden` ⇒ requestAnimationFrame never fires ⇒ animations/CountUp frozen; verify state via DOM/computed style instead.
- Dev server restarts itself ("approaching memory threshold") if too many routes compile in one session. For a whole-app crawl: stop dev, `rm -rf .next`, `NODE_OPTIONS=--max-old-space-size=6144 npm run build`, `npx next start -p 3000`, then crawl every route through hidden same-origin iframes in the logged-in tab (create iframe → wait ~15s → check body text for /Application error|client-side exception|is not defined/ + iframe `error` events). Restart `npm run dev` afterwards.
- Undefined-identifier check for `@ts-nocheck` files: copy `src`+`app`+tsconfig to scratch, strip `@ts-nocheck`, run `tsc --noEmit`, filter TS2304/TS2552 (was clean). ESLint config is broken (flat-config migration) — do not rely on it.
- Test data: company 2 seeded data, many `ZZ…` throwaway records; never touch the demo account; do not push backend changes.

- HIDDEN-TAB TIMER THROTTLING: after ~5 min a controlled tab's chained setTimeout fires ~1/min, so long `javascript_exec` scripts look like 'renderer frozen' (they are not app bugs). Use fresh tabs (tabs_create_mcp), short scripts, and a MessageChannel-based sleep (see memory `convoyai-testing-and-browser-workflow.md`); kill a spinning renderer with `kill <pid>` if needed.
- Backend pm2 app `convoyai-http` crash-loops (EADDRINUSE 8080) while another instance serves fine — ignore, out of scope.
