## How to re-capture real shapes fast (method that worked)

1. tiny receiver in the scratchpad: node http server on :9999 that writes POST bodies to files; 2) temporary `public/zz-spy.js` (patches XMLHttpRequest, POSTs every `localhost:8080/api` GET response to the receiver with mode:'no-cors') + a temporary `<script src="/zz-spy.js" />` in app/layout.tsx (NEVER commit; `git checkout app/layout.tsx` + delete the file after); 3) load pages in hidden same-origin iframes (3 per call, ~13 s each) so the spy runs in each; 4) inspect with a small python "shape" printer. Alternatively read `backend_frontend_sync/api_contract`.
