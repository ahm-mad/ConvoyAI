# Realtime events (Socket.IO) — payloads and frontend consumption

Server: Socket.IO at `NEXT_PUBLIC_API_URL` origin, path `/socket.io`, handshake `auth:{token}` (same JWT). The socket joins room `user:{id}`; if the JWT has a company AND permission `all-fleet` it also joins `company:{companyId}`. The client never emits. Errors: `connect_error` "Authentication required" | "Invalid token" (no refresh flow). Delivery is best-effort, events are never replayed → refetch on (re)connect/focus and keep slow safety polls.
All ids in payloads are **strings**. Full text: `backend_frontend_sync/api_contract/API_CONTRACT.md` §4.

| Event (room)                                 | Payload                                                                                                                                                                                                                                         | Frontend consumer                                                                                                                                                                                                        |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `packet:initial` (user)                      | `{productId}` — first packet for a newly issued ingestion token                                                                                                                                                                                 | `GlobalPacketListener` → persistent "configure" toast (`bindAllInitialPacketEvents`)                                                                                                                                     |
| `device:value` (user)                        | `{deviceId, productId, cleanedPacket{attr:value}}` — once per ingested packet                                                                                                                                                                   | `ManageDevice` history tab (`bindDeviceValueEvent(productId)`; refetch when the selected device matches)                                                                                                                 |
| `dashboard:update` (user)                    | `{dashboardId, widgets:[{widgetId, values:[{attribute_name, attribute_value, is_alert}]}]}` — only touched widgets (merge by `widgetId`)                                                                                                        | `Grid.tsx` (parked widget dashboard)                                                                                                                                                                                     |
| `building:update` (user)                     | `{buildingId, deviceId, deviceIdentifier, asset}` — `asset` = full tree shaped like `GET /assets/{id}`                                                                                                                                          | `Assets.tsx` `handleBuildingLiveValues` (Unity path, currently unreachable)                                                                                                                                              |
| `alarm:state` (user)                         | `{ruleId, deviceId, state:'alert'\|'normal', message}`                                                                                                                                                                                          | **not consumed**                                                                                                                                                                                                         |
| `notification:new` (user)                    | `{notificationId, title, message}` (durable row exists; dedupe with `GET /notifications`)                                                                                                                                                       | **not consumed** (deferred bell/notification centre)                                                                                                                                                                     |
| `fleet:position` (company)                   | `{vehicleId, deviceId, latitude, longitude, speed\|null, heading\|null, recordedAt(ISO), tripId\|null}` — assigned trackers only, frequent                                                                                                      | `useFleetRealtime`: patch cached `fleet-positions`, `vehicle-detail-{id}`, `trip-route-{tripId}`, `fleet-history-{deviceId}` in place (no refetch per packet; one debounced refetch if a tracker enters the viewed bbox) |
| `geofence:event` (company)                   | `{id, geofenceId, geofenceName, yardId\|null, vehicleId, vehicleName\|null, eventType:'enter'\|'exit', occurredAt, tripId\|null}` (every real transition regardless of `alert_on`)                                                              | invalidate `geofence-events`                                                                                                                                                                                             |
| `trip:update` (company)                      | `{tripId, reason:'created'\|'started'\|'stop_arrived'\|'stop_departed'\|'stop_updated'\|'updated'\|'destination_reached'\|'completed'\|'cancelled'\|'deleted', status, awaitingCompletion, destinationReachedAt\|null, stop\|null, occurredAt}` | invalidate `trips-list*`, `trips-counts*`, `fleet-map-trips`, `trip-{id}`, `trip-route-{id}`, `fleet-dashboard*`                                                                                                         |
| `fleet:changed` (company)                    | `{entity:'vehicle'\|'driver'\|'yard'\|'yard_slot'\|'geofence', id, action:'created'\|'updated'\|'deactivated'\|'reactivated'\|'deleted'\|'checked_in'\|'checked_out', occurredAt}` — no data, "refetch that list"                               | per-entity invalidation (see data-layer doc §4)                                                                                                                                                                          |
| `fleet:status_summary` (company)             | `{total, moving, idle, parked, offline, no_tracker, occurredAt}` — only when counts change, checked once a minute, no heartbeat                                                                                                                 | invalidate `fleet-dashboard-ov-status*` / `-attention*`                                                                                                                                                                  |
| `fleet:connected` (**local**, frontend-only) | raised on every socket (re)connect                                                                                                                                                                                                              | first one ignored, later ones invalidate all fleet keys                                                                                                                                                                  |

Demo mode: `MSW_SOCKET_EVENT` window CustomEvents carry `dashboard:update`, `building:update`, `packet:initial`, `device:value` only.
