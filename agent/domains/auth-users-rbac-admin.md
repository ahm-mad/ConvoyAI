# Domain: auth, users, RBAC, companies & super-admin

## 1. Authentication

- `/login` → `screens/Login.tsx`: react-hook-form + yup (`LoginPageValidation`), `POST /api/login` → `{ success, user, token }` → `handleLogin(user, token)` (localStorage `user`, `token`), `i18n.changeLanguage(user.locale)`, then navigates to `location.state.from || '/home'` if `user.companyInfo` is true, else **`/account-setting`** (company onboarding). Sets `localStorage.isFirstLogin='true'`.
  Demo account `demoAccount@chirptech.io` / `demoAccount-password` → `localStorage.clear()` + `setupDemoMode(true)` (MSW) before the login post — demo mode = fake backend only (see `demo-mode-simulation.md`).
- **Google OAuth popup**: opens a blank popup immediately (avoids blockers), `GET /api/auth/google/redirect` → `{redirect_url}` → popup navigates there; the backend callback page `postMessage`s `{type:'GOOGLE_AUTH_SUCCESS'|'GOOGLE_AUTH_ERROR', token, user}` to `window.opener` — origin checked against `NEXT_PUBLIC_API_URL` origin. COOP headers on the popup make `popup.closed` unreadable, so a 2-minute timeout clears loading. `[GoogleAuth Debug]` logs + interval are marked TEMPORARY (still present).
- `/register` (`POST /register` → verification e-mail with a link to `/verify-token/:token` → `VerifyAccount` calls `POST /verify-token`, `POST /resend-verification-email`), `/forget-password` (`POST /forgot-password`), `/reset-password` (`POST /verify-reset-token`, `POST /reset-password`). Logging in unverified → 403 "Please verify your email first."
- JWT valid **7 days** (backend), embeds roles+permissions (a permission change applies at next login). No refresh flow used; 401 does **not** auto-logout (commented out in `axiosConfig`). Logout: `handleLogout` clears everything and hard-redirects to `/login` (also `POST /logout` exists but isn't used).

## 2. Authorization model (frontend)

- `user.roles[]` each with `permissions[]`; `isSuperAdmin = roles has 'super_admin'`, `isAdmin = roles has 'admin'`; `hasPermission(name)` exact match. Backend also has `platform_operator` role and `manage users` permission.
- **Gating happens only in `LeftSidebar.tsx`** (and a few in-page `user?.isDemo`/`isAdmin` checks). Permission names in use: `all-dashboard` (Home item), `all-product` (Manage Products), `all-connect` (Connector Health), `all-building` (Manage Assets), `all-rule-builder`, `all-fleet`, `all-alarms`, `all-role-permission` (Roles & Permissions), `all-module-management`, `all-plan-management` (both sidebar entries commented out). Super-admin-only items: Companies, Products (`/all-products`), Analytics (`/analytics`).
  Demo users don't see Map/Rule Builder/Roles. **No route guard**: a URL opens regardless of permission (backend 403s). `/devices` route was deleted (2026-09-23).
- Roles/permissions are **module-based**: `GET /modules` returns modules (`slug`); a role stores boolean permission per module slug (`PermissionToggle.tsx` cards with icons by slug: dashboard, device-management, plan-management, module-management, role-management, permission-management, member-management). `POST /roles/create`, `PUT /roles/:id/update`, `GET /roles/:id`, `DELETE /roles/:id/delete` (`CardRole`), `GET /roles/company`.

## 4. Navbar / shell details

`Navbar.tsx` (320 L, 44 px bar): fetches `/api/profile?user_id=` for name/avatar; `ThemeToggle`; avatar popper shows: the user's name (link to account settings), **Account settings (non-demo only)**, Language submenu (English / العربية → `i18n.changeLanguage`), **Simulation (demo users only)**, Logout (`disconnectSocket` + `localStorage.clear()` + `sessionStorage.clear()` + hard redirect). (The `items` array also defines Manage/Assets/Companies/Rules-permissions entries — with a mistyped `/rules-permission` route — but they are filtered out and not rendered.) `RightSidebar.tsx` (user settings preferences `GET /settings/user`, `POST /settings/user/update`) is **not imported anywhere** (Navbar only keeps an unused `rightSidebarOpen` state) — dead. `LeftSidebar.tsx` (692 L): accordion sections Dashboard (Home + `dashboardData` items), Core, Connect, Twin, GIS, Studio, Solutions, Operations; collapsible/pinned/hover-expand desktop, mobile hamburger overlay; `driver.js` tour hooks (`AccordionSection`). Sections render only when they have ≥1 visible item.
`WelcomeIntroModal` (demo first-login only). `Breadcrumb` uses a static route→label map (no Fleet paths).
