# Domain: Home, dashboards & the parked legacy widget system

## Live pieces

- **Home** (`/home` → `screens/Home.tsx`, 295 L): `GET /api/dashboard/analytics` → `{total_devices, online_devices, offline_devices, active_in_last_24h, recently_active_devices[], offline_devices_list[]}`; stat cards with explanatory hints (added 2026-09-23 so "0 online / 3 offline / 3 active in 24h" isn't self-contradictory), device tables (`Tables`), skeleton + error states. Sidebar "Home" requires `isSuperAdmin || hasPermission('all-dashboard')`.
- **Dashboard** (`/dashboard/:id` → `DashboardWrapper` (`key={id}`) → `screens/Dashboard` → lazy `DeviceStatusGrid`): per-device status cards (name, product, DevEUI, `status` manual active/inactive, `last_updated` human string), search, 12/page over `GET /api/devices?per_page&page` (products with nested devices, flattened). Deliberately NO per-attribute widgets and no alert indicator (needs backend logic). Swapped in at the wrapper level so `Grid.tsx` is revertible in one line.
- `AuthLayout` fetches `GET /user/:id/dashboards` for the sidebar list; `DashboardSubNav` (lock toggle via `?lock=true`, delete dashboard `DELETE /dashboards/:id`) shows on `/dashboard/*`.
