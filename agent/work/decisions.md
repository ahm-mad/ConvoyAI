## 2026-09-27 — map realism (T-006-R item #0). Owner delegated every choice ("whatever is recommended, just make it look superb"); revisit any of these later.

Diagnosis (code + live): default demo speed ×20 (~1,200 km/h apparent); straight-line dead reckoning drifting off road bends and snapping back each 700 ms poll; loop vehicles' "stopped" spells only zeroed the reported speed (position kept moving); trips ping-pong with instant U-turns; cluster bubbles re-handed out by pool index every 350 ms (measured 427 px teleports), no easing, hover scale 1.1.
Decisions taken (owner can reverse):

1. Default demo speed ×3 (was ×20); toolbar offers 1× / 3× / 10× / 20× / 60×. 1× is true real time but barely visible below zoom 12.
2. Vehicle motion = buffered interpolation (render ≈ one poll interval in the past, linear between the last two fixes, heading from the actual movement then eased) instead of straight-line dead reckoning; legacy dead reckoning kept for slow real-backend fixes (>2.5 s apart).
3. Simulated trips get a trapezoid speed profile (accelerate / cruise / brake at each end, dwell at the ends); loop vehicles really stop (position frozen during stop windows, not only the speed number).
4. Cluster bubbles: stable identity (keyed by lowest member id), eased centroid glide, no hover scale (soft ring instead).
5. Route highlight: selecting a vehicle highlights its road (bright ahead / dimmed driven, glow); vehicles on an active trip use the rich trip RouteLayer (beacons + ETA), others (loop vehicles) get the mission road highlight. Not always-on for all vehicles (visual clutter); hover shows a soft preview.
6. (added after building) Route highlight uses ONE style for all vehicles (MissionRouteLayer) rather than auto-opening the trip RouteLayer; the dropdown still adds beacons + ETA. Landing hero stays ×30 (country-level time-lapse). Old saved demo-speed choices reset (key v2). Not verified: real-backend mode (mission route is showcase-only), 3D/tilt look of the route line, mobile widths.
7. (2026-09-27, owner: "go with your recommendation") Route detail split: hover = road + small labelled start/destination beacons only; selected vehicle or chosen trip = full detail (named start/destination, yards + geofences within 800 m of the road emphasised, geofence name tags). Showcase geofences moved onto the highways / 3 added so this is visible. Trip-modal map: name tags only.
