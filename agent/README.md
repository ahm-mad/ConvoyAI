## 0. What this project is (30 seconds)

**ConvoyAI** — an enterprise IoT / digital-twin platform frontend (Next.js 15 App Router + TypeScript, React 19,
Tailwind v4, MUI + Radix + antd coexisting). It manages IoT products/devices, dashboards, a 3D asset/building
twin, a rule builder (alarms → email/SMS/notification), RBAC, and — the actively developed part — a large
**Fleet Management** module (vehicles, drivers, trackers, yards, geofences, trips, realtime map, and an
analytics/reports area) running against a **separate Express + Supabase(Postgres) backend** (another repo,
**OUT OF SCOPE for this workspace** — treat it as an API described by `backend_frontend_sync/api_contract`).
The app was migrated React+Vite → Next+TS on 2026-09-09; behaviour is unchanged by the migration.
This workspace (`/media/chirp/Personal/Freelancing/convoyai`) is a **copy** of the original repo folder
`FE-ConvoyAI` (branch `feat/next-ts-migration`); here it has one commit ("transfered") on `main`, **no git
remote**, and **`node_modules` is NOT installed** (run `npm install` before `dev`/`build`/`typecheck`).

The user (owner) is a freelancer working with a boss/client; owner-only decisions are recorded in
`rules/owner-rules-and-workflow.md`. **Read that file before touching anything.**
