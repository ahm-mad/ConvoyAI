## 2. Data hooks → endpoints

| Hook                                       | Endpoints (all `/api/…`)                                                                                                                                                                                                                                                                                                                            |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `useOverviewData(f, {severity, rankBy})`   | `fleet/dashboard` (current+previous), `fleet/dashboard/trends` (+14-day spark), `vehicles/counts`, `compliance-documents/counts`, `drivers?license_state=…&per_page=1`, `fleet/analytics/yards`, `geofences/events/summary`, `fleet/dashboard/vehicle-performance` (top 6 server-ranked), `incidents`, `fleet/analytics/summary` (B1, compare `none | previous_period | previous_year`), `fleet/attention`(B2),`fleet/status-summary`(B3),`maintenance-schedules` counts (C1) |
| `useAnalyticsData(f,{vehicles?})`          | dashboard current/previous, trends current/previous, server-paged performance table (A8)                                                                                                                                                                                                                                                            |
| `useTripsReport(q)`                        | `fleet/analytics/trips` (+`/export`)                                                                                                                                                                                                                                                                                                                |
| `useFuelReport(q)`                         | `fleet/analytics/fuel` (+`/export`)                                                                                                                                                                                                                                                                                                                 |
| `useMaintenanceReport(q)`                  | `fleet/analytics/maintenance`                                                                                                                                                                                                                                                                                                                       |
| `useMaintenanceSchedules(q)`               | `maintenance-schedules` (+`/export`)                                                                                                                                                                                                                                                                                                                |
| `useCompanyLogs('maintenance'\|'fuel', q)` | `maintenance-logs`, `fuel-logs` (+`/export`) with `meta.summary`                                                                                                                                                                                                                                                                                    |
| `useComplianceReport(q)`                   | `fleet/analytics/compliance` (+`/export`); point-in-time: no range, no compare; `horizon_days` 7–365, interval week (month if >180)                                                                                                                                                                                                                 |
| `useFleetSettings`, `useUnits`             | `fleet/settings`                                                                                                                                                                                                                                                                                                                                    |

Query names start with `fleet-dashboard-ov-*` / `fleet-dashboard-an-*` so realtime refetches them; `refetchInterval` 300 000; `keepPreviousData`. Request `interval` = user choice or auto (`day ≤92 d, week ≤644 d, else month`). Exports send the same scope/filters/sort as the table (paging ignored).

## 3. Report pages (what each shows)

- **Overview** (`FleetOverview.tsx`, ~1000 L): filter bar + KPI tiles (availability, utilisation, on-time, cost/distance, fuel economy, open issues; values from B1 with `delta_pct`/target; null → "—"; units converted via `useUnits`), widgets: Fleet status (donut, live), Needs attention (worklist, server severity filter, entity → modal), Trips, Utilisation trend (target line), Maintenance & compliance (bucket bars), Yard occupancy, Geofence activity, Incidents (8 weeks by severity), Where the money goes (cost donut), Top vehicles (rank bars with metric tabs). The page scrolls in its own container. "Active trips" live table from the design is NOT built.
- **Utilisation**: 4 KPIs + trend w/ target + distance per day + server-sorted vehicle table; row → vehicle modal. **Trips & delivery**: see fleet.md. **Fuel & efficiency**: flags worded as "check" (over_capacity, economy_drop, odometer_backwards). **Maintenance**: 3 views via `?view=`. Compliance donut doubles as table filter.
- **Fleet settings** (`FleetSettings.tsx` + `fleetSettings/controls.tsx`): sections Company time / Live tracking / Working day & delivery / Maintenance planning / Targets; "In use" vs "Used by upcoming reports" chips; client validation mirrors backend 422 rules; per-field Default reset; timezone-change warning; PUT sends changed fields only; 409 via `useEditConflict`; beforeunload guard; unit cards (metric/us/uk) shown only when the API returns `unit_system`.

## 4. Verified behaviours & lessons (from live testing)

Widths 820/1280/1536/1920/2560: no page overflow; tables scroll inside their wrapper at narrow widths. Scale-safe: pager jump, server counts on chips, server-ranked top vehicles (tested with a 10,000-vehicle mock). Tooltips are value-first; single-day range works; tick labels show the year on multi-year ranges.
Lessons: single-slice donut draws an empty ring unless handled; count axes must be whole numbers; curved lines invent shape between daily points (use straight); Tailwind `min-[1760px]` loses to `lg:` in the cascade → size columns from container width; truncated legend labels in narrow cards → container-width-based.
