# Domain: public marketing site (guest pages)

Routes (`app/(public)`): `/` (`screens/GuestHome.tsx`), `/use-cases` (`screens/UseCases.tsx` = Navbar + `UseCasesShowcase` + Footer; `GuestHomeComponents/pages/{Home,UseCases}.tsx` are unused legacy with a broken `@/components/sections` import), `/plan-price` (`PlanAndPrice` — a placeholder of three empty "NON-COMMERCIAL" cards), plus auth pages `/login`, `/register`, `/forget-password`, `/reset-password`, `/verify-token/:token`.
`NonAuthLayout` is a bare wrapper (nav/footer commented out); the landing page brings its own `Navbar`/`Footer`.

- `GuestHome` composes `GuestHomeComponents/components/sections/*`: Hero (video `hero-twin.mp4`, fonts `hero-fonts.css`), SystemArchitecture, ProtocolIngestion, SpatialIntelligenceIntro, AIAgents, EnterpriseCapabilities, IndustryVerticals, CommandCenter, CaseStudies, TechStack, WhyChoose, FinalCTA (`UseCasesShowcase` for the use-cases page); layout `Navbar` (nav links from `data/navigation.ts`: Home section link + Use Cases route), `Footer`, `ScrollToSection`; UI atoms `Button`, `Container`, `Eyebrow`. Content lives in `GuestHomeComponents/data/*.ts` (agents, architecture, capabilities, caseStudies, footer, hero, industries, navigation, protocols, techStack, useCases, whyChoose).
- **Styling**: uses the app-wide Tailwind tokens from `src/index.css` (imported by the root layout) plus arbitrary colours; page background `bg-[#0F1D2A]`, root font-family Orbitron (inline style; loaded nowhere explicitly — falls back). `GuestHomeComponents/index.css` (Inter/JetBrains Mono via `@fontsource`, its own `@theme`) is **NOT imported anywhere** (legacy from the pre-merge repo; `@fontsource/inter` isn't even a dependency). `Hero.tsx` imports its own `hero-fonts.css`. `styles/global.css` (Calendly overlay fixes, `.bg-grid`, `.text-gradient-cyan`) is imported by `GuestHome.tsx`. Assets in `GuestHomeComponents/assets` (+ `src/assets/images`, `LandingPageVideo`).
- Booking: `lib/cal.ts` (`@calcom/embed-react`, placeholder `CAL_LINK='your-username/30min'` — **not configured**), `react-calendly` also installed.
- Rendered client-only (the `ssr:false` shell) → **no SEO today**; Phase 8 (Metadata API, sitemap, robots, Server Components for `/`, `/use-cases`, `/plan-price`, blog) is a separate deferred task and would require pulling these routes OUT of the `ssr:false` shell and guarding any `window`/`localStorage` access.
- `components/NonAuthNavBar.tsx` / `NonAuthFooter.tsx` are unused legacy.
